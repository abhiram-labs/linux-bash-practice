# Linux & Bash Practice

A collection of Bash scripts created while learning Linux
administration and shell scripting.

## Topics Covered

- Variables and user input
- Conditional statements
- Loops
- Functions
- File and directory checks
- System information
- Service and package checks
- Backup scripting

## Requirements

- Linux or Ubuntu
- Bash shell

## Usage

Make a script executable:

    chmod +x script-name.sh

Run it:

    ./script-name.sh

## Purpose

This repository documents my hands-on Linux and Bash
learning journey and practical scripting exercises.
